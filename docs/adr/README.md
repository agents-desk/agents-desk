# 架构决策记录

这里记录 agents-desk 中重要的、以后难改的技术决定（Architecture Decision Record，ADR）。每篇写清楚当时的背景、做了什么决定、考虑过哪些做法，以及这个决定带来的约定和代价。以后有人问“为什么这样做”，答案在这里。

## 怎样写

- 一篇一个决定，文件名是 `<四位编号>-<标题>.md`，编号依次递增。
- 格式：开头写状态和日期，然后是**背景**、**决定**、**考虑过的做法**、**后果**四节，一两页即可。
- 状态：`已采纳`、`已被 00xx 取代`。
- 已采纳的 ADR 不再修改内容。决定变了，新写一篇，并把旧的那篇的状态改为“已被 00xx 取代”。
