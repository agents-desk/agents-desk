# agents-desk 开发计划

- 状态：讨论稿
- 日期：2026-11-20

计划按阶段划分，每个阶段由若干计划项组成。每个计划项对应一个或几个 PR，这里只定它的目标、主要内容和依赖，具体做法在开发时确定。依赖列为空的计划项可以同时开始。

---

## 做法

- **每个 PR 合并后应用都能运行**，可以单独验收。
- **内核先行，尽早合并。** 第 1 阶段的公共依赖只有会话内核（K1）。它只包含各计划项都要用的模型和写入路径，其余功能放到各自的计划项中。
- **接口先行。** 前后端分开的计划项，先合并接口定义和种子数据，之后前端和后端同时开发。
- **阶段可以重叠。** 后面阶段中依赖已经满足的计划项可以提前开始，例如知识库的内容管理、Telegram 连接器。
- **已有的代码按新设计调整。** 现有的成员、角色、团队在第 1 阶段改造，沿用原来的表和接口。

## 已完成

管理员端和工作区；成员登录和切换工作区；个人资料；偏好设置（语言、时区）；成员和角色（主管理员、管理员、组长、坐席四个固定角色）；团队。

## 第 1 阶段：客服 MVP

目标：第一个产品的网页咨询全部在 agents-desk 中处理，坐席用自己的语言工作。

依赖关系：

```
立即开始 ──┬─ F1 布局   F2 界面多语言   F3 前端骨架   F4 实时推送
           ├─ A1 角色   A2 团队收件箱   A3 在线状态   A4 工作时间
           └─ K1 会话内核
                 │
K1 合并后 ───────┼─ C1 聊天插件后端 ── C2 聊天插件前端
                 ├─ D1 收件箱后端 ──── D2 收件箱前端（还需要 F1）
                 ├─ T1 翻译后端 ────── T2 翻译前端（还需要 D2）
                 ├─ E1 指派（还需要 A2、A3）
                 ├─ M1 快捷回复   P1 属性和标签   U1 联系人
                 ├─ AU1 内置自动化（还需要 A4）
                 └─ R1 基础报表
                                        │
全部完成后 ─────────────────────────────┴─ X1 内部试用
```

| 编号 | 计划项 | 主要内容 | 依赖 |
|---|---|---|---|
| F1 | 布局 | 在框架中扩展 RailLayout：页面可以铺满内容区；二级导航留出插槽，模块可以放自己的面板。框架发版后升级 | |
| F2 | 界面多语言 | 框架提供界面文字的翻译机制，组件的文字写进翻译文件；agents-desk 现有页面改用翻译文件，第一版只有中文 | |
| F3 | 前端骨架 | 去掉旧的占位页，按新的界面结构建立收件箱、联系人、报表三个模块和设置的分组 | |
| F4 | 实时推送 | 接入实时频道：成员的个人频道、会话的频道；前端收到推送后刷新对应的数据。会话频道在 K1 合并后接上 | |
| A1 | 角色 | 角色改为管理员创建的权限组合，会话可见范围三选一；现有的四个固定角色迁移为默认的角色 | |
| A2 | 团队收件箱 | 现有的团队改为团队收件箱，加上分配方式（手动、轮流） | |
| A3 | 在线状态 | 在线、离开，离开时可以勾选“把我的会话重新分配” | |
| A4 | 工作时间 | 工作区的默认工作时间、节假日、通常的回复时间；团队收件箱可以单独设置（这部分在 A2 之后） | |
| K1 | 会话内核 | 联系人和渠道身份；渠道和连接器接口；服务型会话、参与者、时间线；统一写入路径和提交后的分发；转派、属性修改等写成时间线中的系统事件；种子数据 | |
| C1 | 聊天插件：后端 | 聊天插件渠道的设置和嵌入代码；访客编号、产品后端签名传来的用户身份；收发消息、历史、送达状态 | K1 |
| C2 | 聊天插件：前端 | 新的前端：嵌入脚本和聊天窗口；会话列表、聊天、评价 | C1 的接口 |
| D1 | 收件箱：后端 | 收件箱各列表和数量；筛选和排序；会话的操作（指派、关闭、稍后处理、优先级、标签、属性）；稍后处理到期、重新打开 | K1 |
| D2 | 收件箱：前端 | 五栏界面；时间线；回复框和内部备注、@ 同事；侧栏 | F1、D1 的接口 |
| T1 | 翻译：后端 | 识别语言并翻译，存为派生内容；发送前的译文和回译；术语表、语气；记录每次模型调用 | K1 |
| T2 | 翻译：前端 | 原文和译文切换；回复框下方的译文和回译；术语表和语气的设置页 | D2、T1 |
| E1 | 指派 | 默认指派、轮流分配、回复即领取、离开时重新分配、同时领取时先到者生效 | K1、A2、A3 |
| M1 | 快捷回复 | 共享和个人；插入联系人字段、附带操作；设置页。回复框中的使用在 D2 之后接上 | K1 |
| P1 | 属性和标签 | 联系人和会话的自定义属性、标签；设置页 | K1 |
| U1 | 联系人 | 联系人列表和资料页；线索登录后合并到用户 | K1 |
| AU1 | 内置自动化 | “触发 → 条件 → 动作”的最小实现；告知回复时间、请线索留联系方式、关闭后请客户评价 | K1、A4 |
| R1 | 基础报表 | 会话、响应时间、满意度、成员、翻译 | K1 |
| X1 | 内部试用 | 第一个产品的网页咨询接入，团队内部使用，修问题 | 以上全部 |
